# 代码验证指南 —— 角色 A 模块

## 验证方式概述

Verilog 代码有两种验证方式：

| 方式 | 工具 | 优点 | 缺点 |
|:----|:----|:----|:----:|
| **仿真验证** | ModelSim / Quartus 内置仿真器 | 能看到波形，容易调试 | 需要写 Testbench |
| **综合验证** | Quartus 编译器 | 检查能否烧录到芯片 | 不检查功能正确性 |

**建议流程：先仿真，后综合。**

---

## 方式一：在 Quartus 中运行仿真

### 第 1 步：打开 Quartus 并添加文件

1. 打开 Quartus II 9.0
2. `File → Open Project`，选择 `CPU.qpf`
3. `Project → Add/Remove Files in Project`：
   - 添加 `timing_gen.v`
   - 添加 `instruction_decoder.v`
   - 添加 `alu_control.v`
4. 点击 OK，关闭对话框

### 第 2 步：将 Testbench 设为仿真顶层

1. `Assignments → Settings`
2. 左侧选择 `Simulator Settings`
3. 在 `Simulation input` 中，选择 `sim/tb_timing_gen.v`
4. 点击 OK

### 第 3 步：运行仿真

1. `Processing → Start Simulation`
2. 如果成功，会自动弹出波形窗口
3. 如果没有波形窗口：`View → Waveform`

### 第 4 步：观察波形，对照检查

在波形窗口中你应该看到：

```
时间轴(ns):  0    500  1000  1500  2000  2500  3000
clk:        0     1     0     1     0     1     0
count:      0           1           2           0
t1:         1_____|‾‾‾‾|__________________|‾‾‾‾|
t2:         ________________|‾‾‾‾|__________________
t3:         ________________________|‾‾‾‾|__________
w1:               |‾‾‾‾|_____________|‾‾‾‾|________
w2:               ________|‾‾‾‾|_____________|‾‾‾‾|
w3:               ________________|‾‾‾‾|____________
```

**检查清单：**

- [ ] T1/T2/T3 依次变为高电平，**不重叠**
- [ ] 每个高电平持续 **500ns ~ 1500ns**（宽度 = 1000ns = 1μs）
- [ ] 从 T1 到下一个 T1 的间隔 = **3000ns = 3μs**
- [ ] W1 在 T1 的高电平期间出现，但略有偏移
- [ ] 所有信号在复位期间（reset_n=0）保持为 0

## 方式二：使用 ModelSim（更专业的仿真）

如果安装了 ModelSim，可以用命令行快速仿真：

### 时序发生器仿真

```bash
# 编译文件
vlog timing_gen.v sim/tb_timing_gen.v

# 启动仿真
vsim -c tb_timing_gen

# 查看波形
run 20000ns
```

### 指令译码器仿真

1. 创建 `sim/tb_instruction_decoder.v`
2. 测试所有 10 条指令的译码是否正确
3. 运行仿真，检查每个输入对应的输出

## 各模块验证用例

### timing_gen.v 验证

| 测试用例 | 输入 | 预期输出 | 检查方法 |
|:--------|:----|:---------|:--------|
| 复位测试 | reset_n=0 | t1=t2=t3=0, w1=w2=w3=0 | 看波形，仿真会自动检查 |
| 正常时序 | reset_n=1 | T1→T2→T3 循环 | 看波形，检查是否依序变化 |
| 周期检查 | reset_n=1 | 每个 T 信号宽度 = 1μs | 测量波形中的高电平时间 |
| 循环检查 | reset_n=1 | 循环周期 = 3μs | 测 T1 上升沿到下次 T1 上升沿 |

## 常见问题排查

### Q: 仿真后波形全是一条直线（没有变化）

可能原因：

| 原因 | 检查方法 | 解决方法 |
|:----|:--------|:--------|
| 时钟没生成 | 看 clk 有没有在跳变 | 检查 Testbench 中的 clock 生成代码 |
| 复位一直有效 | 看 reset_n 是不是始终为 0 | 检查 Testbench 中是否释放了复位 |
| 模块没连接对 | 看 UUT 实例化的端口名是否匹配 | 检查端口连线 |
| 没有添加源文件 | Quartus 工程没包含 .v 文件 | Project → Add/Remove Files |

### Q: 编译报错

| 错误信息 | 原因 | 解决 |
|:--------|:----|:----|
| `can't resolve module timing_gen` | 没添加 timing_gen.v 到工程 | 添加文件 |
| `expecting "endmodule"` | 语法错误，漏了 endmodule | 检查文件末尾 |
| `port size mismatch` | 端口位宽不匹配 | 检查端口声明 |

### Q: 仿真输出全是 X（未知态）

原因是信号没有被驱动。检查：
1. 时钟是否在运行
2. 复位是否正确释放
3. 模块实例化的线是否连对了

## 何时算"验证通过"

当你确认以下全部满足时，角色 A 的三个模块才算验证完成：

- [ ] `timing_gen.v` 波形符合预期时序图
- [ ] `instruction_decoder.v` 所有 10 条指令译码正确
- [ ] `alu_control.v` 各指令在不同节拍的输出正确
- [ ] 没有锁存器警告（Quartus 编译时无 "inferred latch" 警告）
- [ ] 三个文件在 Quartus 中编译通过无错误
