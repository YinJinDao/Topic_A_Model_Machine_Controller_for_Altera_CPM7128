# TEC-8 模型机控制器 — 模块接口定义

## 全局信号约定

| 信号 | 方向 | 说明 |
|:----|:----:|:------|
| `clk` | 输入 | MF 主时钟（1μs 周期，50% 占空比） |
| `reset_n` | 输入 | 异步复位，低有效 |
| `t1, t2, t3` | 内部 | 时序节拍脉冲 |
| `w1, w2, w3` | 内部 | 写选通脉冲 |

### TEC-8 控制信号全集（供所有模块引用）

**输出型（控制器 → 数据通路）：**

| 信号 | 位宽 | 说明 |
|:----|:----:|:------|
| `ARINC` | 1 | AR 地址寄存器加 1 |
| `CIN` | 1 | ALU 进位输入控制 |
| `DRW` | 1 | 数据寄存器 DR 写使能 |
| `LPC` | 1 | PC 加载 |
| `LAR` | 1 | AR 加载 |
| `LIR` | 1 | IR 加载 |
| `LDZ` | 1 | Z 标志寄存器加载 |
| `LDC` | 1 | C 标志寄存器加载 |
| `PCINC` | 1 | PC 加 1 |
| `PCADD` | 1 | PC 加偏移量（跳转） |
| `SELCTL` | 1 | 选择器控制（跳转目标选择） |
| `M` | 1 | 存储器读写模式 |
| `MEMW` | 1 | 存储器写使能 |
| `STOP` | 1 | 停机信号 |
| `SHORT` | 1 | 短指令周期 |
| `LONG` | 1 | 长指令周期 |
| `ABUS` | 1 | A 总线使能 |
| `SBUS` | 1 | S 总线使能 |
| `MBUS` | 1 | M 总线使能 |
| `SST0` | 1 | 状态位 SST0 控制 |
| `S` | 2 | 状态位 [S1, S0] |
| `SEL` | 2 | 选择器 [SEL1, SEL0] |

**输入型（数据通路 → 控制器）：**

| 信号 | 位宽 | 说明 |
|:----|:----:|:------|
| `ir` | 4 | IR7-IR4 指令操作码 |
| `c_flag` | 1 | 进位标志 C |
| `z_flag` | 1 | 零标志 Z |
| `sw` | 3 | 拨码开关 SWC/SWB/SWA |

## 模块一：timing_gen（角色 A）

**文件：** `timing_gen.v`

**功能：** 从 MF 主时钟产生 6 个时序相位信号

```
         ┌─────────────────┐
 clk ────│                 │──── t1
         │    timing_gen   │──── t2
reset_n ─│                 │──── t3
         │                 │──── w1
         │                 │──── w2
         │                 │──── w3
         └─────────────────┘
```

### 端口定义

| 端口 | 方向 | 位宽 | 类型 | 说明 |
|:----|:----:|:----:|:----:|:------|
| `clk` | 输入 | 1 | wire | MF 主时钟 |
| `reset_n` | 输入 | 1 | wire | 异步复位，低有效 |
| `t1` | 输出 | 1 | reg | 时序相位 1（高电平 1μs） |
| `t2` | 输出 | 1 | reg | 时序相位 2（高电平 1μs） |
| `t3` | 输出 | 1 | reg | 时序相位 3（高电平 1μs） |
| `w1` | 输出 | 1 | reg | 写选通 1（T1 后半段） |
| `w2` | 输出 | 1 | reg | 写选通 2（T2 后半段） |
| `w3` | 输出 | 1 | reg | 写选通 3（T3 后半段） |

### 时序图

```
clk    ___|‾|___|‾|___|‾|___|‾|___|‾|___|‾|___
t1       |‾‾‾|       |‾‾‾|       |‾‾‾|
t2           |‾‾‾|       |‾‾‾|       |‾‾‾|
t3               |‾‾‾|       |‾‾‾|       |‾‾‾|
w1         |‾‾‾|       |‾‾‾|       |‾‾‾|
w2             |‾‾‾|       |‾‾‾|       |‾‾‾|
w3                 |‾‾‾|       |‾‾‾|       |‾‾‾|
```

### 行为规范

| 条件 | 行为 |
|:----|:-----|
| `reset_n = 0` | 所有输出置 0，计数器清零 |
| `reset_n = 1` | 每个 `clk` 上升沿计数器 mod 3 递增 |
| 计数值 0 | t1=1, t2=0, t3=0 |
| 计数值 1 | t1=0, t2=1, t3=0 |
| 计数值 2 | t1=0, t2=0, t3=1 |
| 每个 clk 下降沿 | 根据当前计数值产生 w1/w2/w3（与 T 相位半周期偏移） |

### 依赖关系

- **无依赖**（基础模块，可独立开发验证）

## 模块二：instruction_decoder（角色 A）

**文件：** `instruction_decoder.v`

**功能：** 将 IR7-IR4 指令码解码为单指令标识信号

```
          ┌─────────────────────────┐
          │                        │── is_add
          │                        │── is_sub
          │                        │── is_and
ir[3:0] ──│  instruction_decoder   │── is_inc
          │                        │── is_ld
          │                        │── is_st
          │                        │── is_jc
          │                        │── is_jz
          │                        │── is_jmp
          │                        │── is_stp
          └─────────────────────────┘
```

### 端口定义

| 端口 | 方向 | 位宽 | 类型 | 说明 |
|:----|:----:|:----:|:----:|:------|
| `ir` | 输入 | 4 | wire | IR7-IR4 指令操作码 |
| `is_add` | 输出 | 1 | reg | ADD (0001) |
| `is_sub` | 输出 | 1 | reg | SUB (0010) |
| `is_and` | 输出 | 1 | reg | AND (0011) |
| `is_inc` | 输出 | 1 | reg | INC (0100) |
| `is_ld` | 输出 | 1 | reg | LD (0101) |
| `is_st` | 输出 | 1 | reg | ST (0110) |
| `is_jc` | 输出 | 1 | reg | JC (0111) |
| `is_jz` | 输出 | 1 | reg | JZ (1000) |
| `is_jmp` | 输出 | 1 | reg | JMP (1001) |
| `is_stp` | 输出 | 1 | reg | STP (1110) |

### 译码表

| ir[3:0] | 指令 | 输出信号 |
|:-------:|:----:|:--------|
| 0001 | ADD | `is_add=1` |
| 0010 | SUB | `is_sub=1` |
| 0011 | AND | `is_and=1` |
| 0100 | INC | `is_inc=1` |
| 0101 | LD | `is_ld=1` |
| 0110 | ST | `is_st=1` |
| 0111 | JC | `is_jc=1` |
| 1000 | JZ | `is_jz=1` |
| 1001 | JMP | `is_jmp=1` |
| 1110 | STP | `is_stp=1` |
| 其他 | — | 全部输出 0 |

### 依赖关系

- **无依赖**（纯组合逻辑，可独立开发验证）

## 模块三：alu_control（角色 A）

**文件：** `alu_control.v`

**功能：** 根据指令类型产生 ALU 操作控制信号（CIN、LDZ、LDC）

```
                    ┌──────────────────┐
 is_add ────────────│                  │
 is_sub ────────────│                  │─── cin
 is_and ────────────│   alu_control    │─── ldz
 is_inc ────────────│                  │─── ldc
 is_ld  ────────────│                  │
                    └──────────────────┘
```

### 端口定义

| 端口 | 方向 | 位宽 | 类型 | 说明 |
|:----|:----:|:----:|:----:|:------|
| `is_add` | 输入 | 1 | wire | ADD 指令标识 |
| `is_sub` | 输入 | 1 | wire | SUB 指令标识 |
| `is_and` | 输入 | 1 | wire | AND 指令标识 |
| `is_inc` | 输入 | 1 | wire | INC 指令标识 |
| `is_ld` | 输入 | 1 | wire | LD 指令标识 |
| `t1, t2, t3` | 输入 | 1 | wire | 时序节拍 |
| `cin` | 输出 | 1 | reg | ALU 进位输入 |
| `ldz` | 输出 | 1 | reg | Z 标志加载控制 |
| `ldc` | 输出 | 1 | reg | C 标志加载控制 |

### 行为规范

| 条件 | cin | ldz | ldc |
|:----|:---:|:---:|:---:|
| ADD 且在运算节拍 | 0 | 1 | 1 |
| SUB 且在运算节拍 | 1 | 1 | 1 |
| AND 且在运算节拍 | 0 | 1 | 0 |
| INC 且在运算节拍 | 1 | 1 | 1 |
| LD 且在写寄存器节拍 | 0 | 0 | 0 |
| 其他 | 0 | 0 | 0 |

### 依赖关系

- **输入依赖：** `instruction_decoder` 的输出信号
- **输入依赖：** `timing_gen` 的时序信号

## 模块四：control_unit（角色 B）

**文件：** `control_unit.v`

**功能：** TEC-8 全部指令的控制信号组合逻辑（核心模块）

```
                    ┌────────────────────────────────────┐
 t1, t2, t3 ────────│                                    │── ARINC
 w1, w2, w3 ────────│                                    │── CIN
 is_add~is_stp ─────│                                    │── DRW
 c_flag, z_flag ────│           control_unit             │── LPC
 sw[2:0] ───────────│                                    │── LAR
                    │                                    │── LIR
                    │                                    │── LDZ
                    │                                    │── LDC
                    │                                    │── PCINC
                    │                                    │── PCADD
                    │                                    │── SELCTL
                    │                                    │── M, MEMW
                    │                                    │── STOP
                    │                                    │── SHORT/LONG
                    │                                    │── ABUS/SBUS/MBUS
                    │                                    │── SST0
                    │                                    │── S[1:0]
                    │                                    │── SEL[1:0]
                    └────────────────────────────────────┘
```

### 端口定义

| 端口 | 方向 | 位宽 | 类型 | 说明 |
|:----|:----:|:----:|:----:|:------|
| `t1, t2, t3` | 输入 | 1 | wire | 时序节拍（来自 timing_gen） |
| `w1, w2, w3` | 输入 | 1 | wire | 写选通（来自 timing_gen） |
| `is_add, is_sub, is_and, is_inc` | 输入 | 1 | wire | 运算类指令（来自 instruction_decoder） |
| `is_ld, is_st` | 输入 | 1 | wire | 访存类指令（来自 instruction_decoder） |
| `is_jc, is_jz, is_jmp` | 输入 | 1 | wire | 跳转类指令（来自 instruction_decoder） |
| `is_stp` | 输入 | 1 | wire | 停机指令（来自 instruction_decoder） |
| `c_flag` | 输入 | 1 | wire | 进位标志 |
| `z_flag` | 输入 | 1 | wire | 零标志 |
| `sw` | 输入 | 3 | wire | 拨码开关 SWC/SWB/SWA |
| 输出信号 | 输出 | 1 each | reg | 所有 TEC-8 控制信号（见全局信号表） |

### 控制信号真值表（示例节选）

取指周期（所有指令共享）：

| 节拍 | LIR | PCINC | LAR | SBUS | 其他 |
|:---:|:---:|:-----:|:---:|:----:|:----:|
| T1 | 1 | 1 | 0 | 0 | — |
| T2 | 0 | 0 | 1 | 1 | — |
| T3 | 0 | 0 | 0 | 0 | — |

ADD 指令执行周期：

| 节拍 | SBUS | ABUS | CIN | LDZ | LDC | SEL[1:0] |
|:---:|:----:|:----:|:---:|:---:|:---:|:--------:|
| T1 | 1 | 1 | 0 | 1 | 1 | 根据 Rs/Rd |
| T2 | 0 | 0 | 0 | 0 | 0 | — |
| T3 | 0 | 0 | 0 | 0 | 0 | — |

### 依赖关系

- **输入依赖：** `timing_gen`、`instruction_decoder`
- **被依赖：** `top.v`（顶层连线）

### 实现要求

- 使用 `case` 语句而非复杂 `if-else`
- 每个 `always @(*)` 块中确保所有分支有完整赋值，防止 latch
- CLR# 复位时所有控制信号置 0

## 模块六：hazard_detection（角色 B）

**文件：** `hazard_detection.v`

**功能：** 检测流水线中的数据冒险，插入阻塞（stall）

### 端口定义

| 端口 | 方向 | 位宽 | 说明 |
|:----|:----:|:----:|:------|
| `id_ex_rs` | 输入 | 2 | ID/EX 级寄存器 Rs |
| `id_ex_rd` | 输入 | 2 | ID/EX 级寄存器 Rd |
| `ex_mem_rd` | 输入 | 2 | EX/MEM 级目标寄存器 |
| `ex_mem_regwrite` | 输入 | 1 | EX/MEM 级寄存器写使能 |
| `mem_wb_rd` | 输入 | 2 | MEM/WB 级目标寄存器 |
| `mem_wb_regwrite` | 输入 | 1 | MEM/WB 级寄存器写使能 |
| `stall` | 输出 | 1 | 阻塞信号（暂停流水线） |
| `forward_a` | 输出 | 2 | ALU 输入 A 转发选择：00=reg, 01=EX/MEM, 10=MEM/WB |
| `forward_b` | 输出 | 2 | ALU 输入 B 转发选择：00=reg, 01=EX/MEM, 10=MEM/WB |

### 冒险检测条件

| 冒险类型 | 检测条件 | 处理方式 |
|:--------|:---------|:--------|
| RAW（读后写） | EX/MEM 的 rd == ID/EX 的 rs/rd，且 regwrite=1 | 转发（forward） |
| RAW（读后写） | MEM/WB 的 rd == ID/EX 的 rs/rd，且 regwrite=1 | 转发（forward） |
| 加载-使用（load-use） | ID/EX 的指令是 LD，且 rd == 下一指令的 rs/rd | 阻塞 1 个时钟周期 + 转发 |

## 模块九：interrupt_controller（角色 D）

**文件：** `interrupt_controller.v`

**功能：** 中断响应与返回控制

### 端口定义

| 端口 | 方向 | 位宽 | 说明 |
|:----|:----:|:----:|:------|
| `clk` | 输入 | 1 | 主时钟 |
| `reset_n` | 输入 | 1 | 复位 |
| `int_req` | 输入 | 1 | 中断请求（来自外部） |
| `int_ack` | 输出 | 1 | 中断响应 |
| `int_en` | 输入 | 1 | 中断使能（来自控制寄存器） |
| `pc_save` | 输出 | 8 | 中断返回地址（PC 现场保存） |
| `is_int_return` | 输出 | 1 | 中断返回指令标识 |
| `save_state` | 输出 | 1 | 状态保存信号 |
| `restore_state` | 输出 | 1 | 状态恢复信号 |

### 替代方案说明

EPM7128 无 LIAR/IABUS 引脚，中断现场保存方案：
- 使用通用寄存器 R3 保存中断返回地址
- 使用 SST0 状态位记录中断状态
- 中断响应时，硬件将当前 PC 写入 R3，然后跳转到中断服务程序入口
- 中断返回时，从 R3 恢复 PC

### 行为

| 条件 | 动作 |
|:----|:------|
| int_req=1 & int_en=1 & 当前指令完成 | 保存 PC→R3，跳转到中断入口 |
| 中断返回指令 | 从 R3 恢复 PC，继续执行 |

| `swa, swb, swc` | 输入 | 1 | K11/F7/J12 | 拨码开关 |
| `ir4, ir5, ir6, ir7` | 输入 | 1 | G12/E11/J11/E12 | 指令寄存器位 |

| 控制信号输出 | 输出 | 1 each | 见引脚表 | 各控制信号输出 |

```
                    ┌───────────────────────────────────────────┐

                    │  │         control_unit (B)        │       │
                    │  │  ARINC,CIN,DRW,LPC,...等控制信号 │       │

                    │                   │                         │
                    │  ┌────────────────▼────────────────┐       │
                    │  │     (连线到芯片输出引脚)           │       │

                    │  │   interrupt_controller (D)   │         │
```
