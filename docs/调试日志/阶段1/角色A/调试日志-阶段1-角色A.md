## 一、模块设计概述

### 1.1 timing_gen.v — 时序发生器

是整个控制器的"心脏"，从 MF 主时钟（1μs 周期）产生 6 个时序相位信号（T1/T2/T3 + W1/W2/W3）。

- **端口**：clk, reset_n → t1, t2, t3, w1, w2, w3
- **实现方式**：2 位模 3 计数器，上升沿更新 T 信号，下降沿更新 W 信号
- **时序规格**：T 信号脉宽 1μs，循环周期 3μs，W 信号偏移半周期

### 1.2 instruction_decoder.v — 指令译码器

将 IR7-IR4 指令操作码翻译为单指令标识信号。

- **端口**：ir[3:0] → is_add, is_sub, is_and, is_inc, is_ld, is_st, is_jc, is_jz, is_jmp, is_stp
- **实现方式**：纯组合逻辑，case 语句译码
- **覆盖指令**：TEC-8 基本指令集 10 条（ADD/SUB/AND/INC/LD/ST/JC/JZ/JMP/STP）

### 1.3 alu_control.v — ALU 控制接口

根据当前指令和时序节拍产生 ALU 控制信号。

- **端口**：指令标识 + t1/t2/t3 → cin, ldz, ldc
- **组合逻辑**：仅在 T1 节拍产生控制信号
- **控制表**：

| 指令 | cin | ldz | ldc |
|:----|:---:|:---:|:---:|
| ADD | 0 | 1 | 1 |
| SUB | 1 | 1 | 1 |
| AND | 0 | 1 | 0 |
| INC | 1 | 1 | 1 |
| LD | 0 | 0 | 0 |

### 2.2 Bug 修复：W 信号多驱动源错误

**问题描述**：Quartus Analysis & Synthesis 时报错：

```
Error (10028): Can't resolve multiple constant drivers for net "w1" at timing_gen.v(129)
Error (10028): Can't resolve multiple constant drivers for net "w2" at timing_gen.v(129)
Error (10028): Can't resolve multiple constant drivers for net "w3" at timing_gen.v(129)
```

**根因分析**：`timing_gen.v` 中 `w1`/`w2`/`w3` 被两个 always 块同时赋值：

**修复方案**：删除上升沿 always 块中的 W 信号复位赋值。

### 2.3 Bug 修复：W 信号相位错位

**问题描述**：首次仿真的时候发现 W 信号相位整体偏移一位。

**仿真数据（修复前）**：
```
时间(ns)  | clk | t1 t2 t3 | w1 w2 w3
20000     |  0  | 1  0  0  | 0  1  0   ← 错误：T1阶段不应是 w2
30000     |  0  | 0  1  0  | 0  0  1   ← 错误：T2阶段不应是 w3
```

**根因分析**：下降沿 always 块直接读取 `count` 寄存器产生 W 信号。但 `count` 在上升沿时就已经已被更新到下一值，导致下降沿读到的是"下一个"计数值，W 信号整体错位一个相位。

**修复方案**：将 W 信号产生逻辑改为跟随 T 信号。

**修复后仿真数据**：
```
时间(ns)  | clk | t1 t2 t3 | w1 w2 w3 | 状态
15000     |  1  | 1  0  0  | 0  0  0  | T1 开始
20000     |  0  | 1  0  0  | 1  0  0  | ✅ T1 后半段 W1 激活
25000     |  1  | 0  1  0  | 1  0  0  | T2 开始
30000     |  0  | 0  1  0  | 0  1  0  | ✅ T2 后半段 W2 激活
35000     |  1  | 0  0  1  | 0  1  0  | T3 开始
40000     |  0  | 0  0  1  | 0  0  1  | ✅ T3 后半段 W3 激活
```
